## Context

Across TripAdvisor's GitLab, hundreds of merge requests are opened every day, and human
reviewers can't give each one the same depth of attention.

## What I built

An AI review bot that automatically reviews merge requests across the company's GitLab,
flagging issues before a human reviewer gets to them.

## Impact

- Hundreds of merge requests reviewed every day.
- More reliable code reaching production.
